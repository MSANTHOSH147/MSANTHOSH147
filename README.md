# ⭐ Featured Project

## SmartLib — Library Management System

A full-stack library management platform designed around **real-world physical book circulation**.

Instead of treating a book as a single database record, SmartLib models individual physical copies with their own identity, QR code, status, condition and circulation state.

### Highlights

- 🔐 JWT authentication & role-based access
- 📚 Book catalogue management
- 🏷️ Physical book-copy inventory
- 📱 QR-based book circulation
- 🔄 Borrow and return workflows
- 📅 Reservation management
- ⏰ Overdue tracking
- 💰 Fine management
- 👨‍💼 Admin dashboard
- 👤 Member dashboard
- 🐳 Dockerized backend
- ☁️ Cloud deployment
